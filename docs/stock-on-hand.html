Stock On Hand

Every item's quantity on hand, per warehouse - sourced live from Pancake (the only place real per-warehouse stock is tracked; the desktop app's own stock count has no warehouse breakdown).

"Refresh from Pancake" only syncs categories marked "Include in Stock Sync" on Category Setup - the Category filter above is just for viewing what's already cached.

The Quantity column is editable - type in how much to order per item, then Print to include it on the printout in place of Quantity On Hand, or Create Purchase Order to turn it into an actual Purchase Order record (requires the Vendor filter above to be set to one vendor first).
