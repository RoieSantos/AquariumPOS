Payment Methods

Pancake records each payment against its own bank-account ID (a long code like cbe9ddfa-8cc8-...). This list gives each ID a name - the name is what the Online Order card's "Paid Via" shows. Sync from Pancake (also runs every night) pulls every payment method with its name from Pancake, plus any other ID used on recent orders; opening an order paid through a new account adds it too. Pancake's name shows by default - type a Name only to override it. Name, Type and Active are never overwritten by a sync. Only visible to super users.
