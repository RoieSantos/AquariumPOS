Warehouse Setup

Warehouses synced from Pancake. Sales Target, Active, and Address are local-only and editable here. Production/Stock Warehouse are editable here too, same as the Local POS's Warehouse Setup - but the Local POS's own sync overwrites them on its next run, so edit there if the change needs to stick. Inactive warehouses are hidden from the Transfer Orders From/To Warehouse lookup. Address is used to plot the warehouse as an origin marker on the Delivery page's map, for any day whose fixed route (Delivery Setup) tags it. Only visible to super users.
