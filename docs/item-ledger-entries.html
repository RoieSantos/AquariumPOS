New Stock Adjustment

Adds or removes stock directly - use it to correct a count or load a few opening balances. A reason is required and shows on the ledger. For many items at once use Load / Count Stock.

Load or Count Stock (CSV)

Upload what is on the shelves and the ledger is set to match. Columns: Item (item code or SKU), Variant (optional - id, SKU or name; needed for an item that has several), Warehouse (name or ID) and Quantity (what you counted). Only the difference from what the ledger holds is posted, so the first upload becomes your opening balances, a later one becomes a stock-take correction, and uploading the same file twice changes nothing. Preview first - the file is applied all together or not at all.
