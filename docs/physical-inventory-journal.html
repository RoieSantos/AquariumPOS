Calculate Inventory

Adds a line for every active item at the location below (one line per variant, for an item that has several) with the ledger's current quantity as Qty. (Calculated). Run it again any time to pick up items you haven't reached yet - it never touches a line you've already given a count to.

After Calculate finishes, fetches each item's current stock straight from Pancake (shown as a progress message below) and overwrites Qty. (Calculated) with it. Slower on a large run - narrow with Category/Item filter first. Falls back to the portal's own figure for anything Pancake doesn't return. Posting still always compares against the portal's live balance either way.
