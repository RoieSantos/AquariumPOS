Item Ledger

Controls what actually writes to the portal's Item Ledger (Item Ledger Entries / Stock On Hand).

On (default): shipping/receiving a Transfer Order posts to the Item Ledger immediately, and a shipment is refused if the From warehouse doesn't have enough stock on the ledger. Off: Qty Shipped/Received still update normally on the Transfer Order itself, but nothing is written to the Item Ledger and the stock check is skipped - useful while testing/cleaning up data without touching SQL directly.

Barcode Printer

Serial barcode labels (100 × 30 mm) print straight to this printer, with no print dialog. Order printouts keep using the normal printer. Needs QZ Tray installed and running on the PC that prints. Without it, labels open in the normal print dialog.

Checking QZ Tray on this PC...

Lets QZ Tray print silently instead of asking "Allow this site?" every time. One-time setup: (1) In QZ Tray: Advanced → Site Manager → + → Create New. It makes a certificate and private key and trusts them on this PC. (2) Paste the certificate (digital-certificate.txt) here and Save. (3) Put the private key (private-key.pem) in the Supabase secret QZ_PRIVATE_KEY and deploy the qz-sign function. The key never goes in this page. (4) On any other PC that prints labels, copy the certificate into QZ Tray's Site Manager too.
